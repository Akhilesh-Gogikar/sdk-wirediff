# Optional ecosystem map

These entries are **optional and informational**. SDK WireDiff does not require, bundle, endorse, or exchange data with any other listed tool, and the list is not a product suite. A related tool is listed only after it is public.

- [SDK WireDiff](https://github.com/Akhilesh-Gogikar/sdk-wirediff) — semantic cross-SDK differential testing (this repository).
- [DirectiveGraph](https://github.com/Akhilesh-Gogikar/directivegraph) — path-specific agent-instruction precedence traces.
- [ReleaseFence](https://github.com/Akhilesh-Gogikar/releasefence) — explainable local checks before a repository release.
- [ReviewBus](https://github.com/Akhilesh-Gogikar/reviewbus) — reviewer-authority and maintainer bottleneck maps.

Each repository has its own scope, security model, license, maturity, and release decision. Inclusion here does not claim integration, interoperability, production readiness, or a shared support commitment.
