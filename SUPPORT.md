# Support

SDK WireDiff is maintainer-supported open-source software with no service-level agreement.

1. Read the [README](README.md) and [troubleshooting guide](docs/TROUBLESHOOTING.md).
2. Reproduce with `fixtures/demo/manifest.json` or another synthetic observation.
3. Search existing issues.
4. File the structured bug form with the exact probe, normalized values, Python version, and sanitized fixture.

Feature proposals should explain a missing semantic distinction and provide the smallest observation envelope that proves it. Provider-specific production capture, credentials, hosted recording, and public accusations about a named SDK are outside the support boundary.

Use the [private advisory route](SECURITY.md) for vulnerabilities. Do not paste production traffic, secrets, or private schemas into issues.
